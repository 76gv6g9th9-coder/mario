P2 · 金属生命 × FUI 向日葵屏交互演示

打开方式
双击 index.html，用 Edge 或 Chrome 打开即可，无需安装或联网。
移动或分享时请保留整个文件夹，assets 内含演示视频。

交互（鼠标跟手版）
1. 不用点击。在预览画面内左右移动鼠标，屏幕按鼠标位置转向。
2. 鼠标越靠左 / 右，屏幕转动幅度越大；回到中间则回正。
3. 转向中途可停住，也可以反向移动；移出预览后保持当前角度。
4. X 图标现在是方向指示器，也可以在它周围左右移动鼠标控制方向。
5. “收回屏幕 / 翻出屏幕”仍使用按钮；收回前自动回正。
6. 键盘 ← / → 转到两端，↑ 回正，↓ 收回 / 翻出。
7. 触屏可在预览画面内左右拖动。
8. 可调节 X 图标大小、光晕和环境明暗；“重置”恢复视觉参数并回正。
9. 沉浸模式与全屏保留。Esc 可退出沉浸模式。

素材处理
图片中 7 段视频的尾部纯黑画面已裁掉，并写回原 DEMO 文件夹。
原片位于 DEMO\原片备份。“合成 4.mp4”未修改。
裁切原片保留原编码、3106×1440 分辨率、30 fps 和音轨，保留画面逐帧校验一致。
网页 assets 使用另外制作的 1920 像素宽 H.264 静音副本，便于浏览器播放。
光影调节是网页视觉效果；视频内显示屏的实体尺寸使用原素材，大小滑杆调节交互 X 按钮。

裁切后有效时长
屏幕翻转出现：5.867 秒
屏幕翻转收回：5.867 秒
屏幕正对循环：5.133 秒
屏幕左转过渡：1.900 秒
左边往中间转：1.667 秒
中间往右边转：2.133 秒
右边往左边转：1.900 秒

跟手转向使用原有左转 / 右转视频逐帧定位，回正时反向定位，不修改原始视频。

金属生命 × FUI 视觉更新
- 钛灰深色金属界面，暖金色电路线与边角刻度。
- 鼠标经过时产生短暂的正交线路、方块和横向光痕；“粒子 ON/OFF”可切换。
- 转向响应刻度采用 -1.00～+1.00 归一化值，不代表真实机械角度。
- “休眠 · 收回”先平滑回正，再播放原收回动画并显示播放进度。
- 收回后点击画面中央的 X“唤醒屏幕”或底部“唤醒 · 展开”，播放展开过程。
- 跟随系统的减少动态效果设置停用装饰粒子及呼吸动画。
